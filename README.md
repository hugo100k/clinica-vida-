# 🏥 Clínica Vida+ — Sistema de Gestão de Clínica

## 📌 Sobre o projeto

O Clínica Vida+ é um sistema de gerenciamento de clínica médica desenvolvido em C#, com o objetivo de facilitar o controle de pacientes, médicos e agendamentos de consultas.

O projeto foi desenvolvido como prática de programação, aplicando conceitos de lógica, orientação a objetos, estruturas condicionais e manipulação de coleções.

## 🎯 Objetivo

Desenvolver uma aplicação capaz de organizar as principais operações de uma clínica médica, proporcionando maior praticidade no gerenciamento de informações e agendamentos.

## 🚀 Funcionalidades

- Cadastro de pacientes.
- Listagem de pacientes cadastrados.
- Cadastro de médicos.
- Listagem de médicos cadastrados.
- Agendamento de consultas.
- Identificação de pacientes e médicos por ID.
- Consulta dos agendamentos realizados.
- Validação de informações.
- Verificação de disponibilidade de horários.

## 🛠️ Tecnologias utilizadas

## ▶️ Como executar o projeto

### Pré-requisitos

- Ter o .NET 8 SDK instalado.
- Ter o Visual Studio Code instalado.

### Passo a passo

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o terminal integrado.
4. Execute o comando:

```bash
dotnet restore
```

5. Em seguida, execute:

```bash
dotnet run
```

6. O menu principal será apresentado no terminal.
